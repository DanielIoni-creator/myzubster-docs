# 🐾 MyZubster Pets - Animals on Blockchain

**Domestic Animals with NFC + Monero Blockchain**

---

## 📌 Overview

MyZubster Pets extends the platform to include domestic animals using NFC tags and GPS tracking, all recorded on the Monero blockchain.

## 🎯 How It Works

### Registration Process

1. **Pet owner** attaches NFC tag to collar
2. **Registers** on MyZubster Pets
3. **Pays** registration fee in XMR
4. **Pet record** is stored on blockchain
5. **Pet appears** on global map

### Data Stored

| Field | Description |
|-------|-------------|
| Name | Pet's name |
| Species | Dog, cat, horse, etc. |
| Breed | Specific breed |
| Birthdate | Age |
| Owner | Monero address |
| GPS | Current location |
| Photos | IPFS hash |
| NFC ID | Unique chip ID |

## 💰 Fee Structure

| Fee Type | Percentage | Destination |
